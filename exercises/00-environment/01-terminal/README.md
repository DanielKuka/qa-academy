# Ката 00-01: термінал

Урок: «Середовище розробника → Термінал: базові команди».

Відкрий `commands.sh` і запиши команди для шести завдань. Тести запускають твій скрипт через bash
у тимчасовій теці й перевіряють, що вийшло на диску. Твої файли в репозиторії скрипт не зачепить.

```sh
npm run check -- exercises/00-environment/01-terminal
```

На Windows потрібен Git for Windows: тести самі знайдуть Git Bash поруч із `git`.

Готово, коли всі тести зелені. Еталонне рішення лежить у `solution/`.
Відкривай його тільки після того, як розв'яжеш сам, щоб порівняти підходи.
