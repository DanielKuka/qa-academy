# Ката 00-06: квест «знайди в документації»

Урок: «Середовище розробника → Як читати документацію і шукати відповіді».

Відкрий `exercise.js`: сім питань, на кожне — коротка відповідь з офіційної документації
(npm, MDN, Playwright, Git, Node.js). Біля кожного питання вказано, де шукати.

```sh
npm run check -- exercises/00-environment/06-reading-docs
```

Тести зберігають лише sha256-хеш правильної відповіді, тож вони не підкажуть її — тільки скажуть,
куди дивитися. Регістр і зайві пробіли не важливі.

Готово, коли всі тести зелені. Еталонні відповіді з посиланнями лежать у `solution/`.
