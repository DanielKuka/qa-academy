# Ката 00-02: Node.js і npm

Урок: «Середовище розробника → Node.js і npm».

У теці `my-project/` лежить маленький проєкт: функція, що рахує результати прогону тестів
(`src/summary.js`), скрипт, який друкує звіт (`src/index.js`), і тести до функції (`test/summary.js`).
Не вистачає лише правильного `package.json` — це і є твоє завдання.

Працюй у терміналі **всередині** `my-project/`:

```sh
cd exercises/00-environment/02-node-npm/my-project
```

## Завдання

1. **Модулі.** Код використовує `import`/`export`. Скажи Node.js, що `.js`-файли проєкту — це
   ES-модулі (одне поле в `package.json`).
2. **Скрипт `start`.** Щоб `npm start` запускав `src/index.js` і друкував звіт.
3. **Скрипт `test`.** Щоб `npm test` запускав тести з теки `test/` вбудованим тест-раннером Node.js
   (жодних бібліотек встановлювати не треба — знайди в документації Node.js, як він запускається).
4. **Залежність для розробки.** Встанови `@playwright/test` **командою npm** (не вписуй руками).
   Це інструмент для тестів, а не для роботи застосунку, — подумай, у який розділ він має потрапити.
5. **Версія Node.js.** Вкажи, що проєкт потребує Node.js 22 або новішої (поле `engines`).

Перевір руками: `npm start` друкує звіт, `npm test` показує 2 пройдені тести.

## Перевірка

З кореня репозиторію:

```sh
npm run check -- exercises/00-environment/02-node-npm
```

`node_modules/` і `package-lock.json`, що з'являться в `my-project/`, — це нормально, вони не комітяться.

Готово, коли всі тести зелені. Еталонне рішення лежить у `solution/`.
Відкривай його тільки після того, як розв'яжеш сам, щоб порівняти підходи.
