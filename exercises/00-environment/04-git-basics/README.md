# Ката 00-04: Git — перші кроки

Урок: «Середовище розробника → Git: перші кроки».

Відкрий `git-steps.sh` і запиши команди для чотирьох завдань. Тести створюють тимчасовий
git-репозиторій, запускають у ньому твій скрипт через bash і перевіряють гілки, коміти та їхній вміст.
Твій справжній репозиторій скрипт не зачепить.

```sh
npm run check -- exercises/00-environment/04-git-basics
```

Готово, коли всі тести зелені. Еталонне рішення лежить у `solution/`.
Відкривай його тільки після того, як розв'яжеш сам, щоб порівняти підходи.
