# Ката 01-11: область видимості і замикання

Урок: «JavaScript: основи → Область видимості і замикання».

Відкрий `exercise.js` і виконай чотири завдання з коментарів `TODO`. Жодних глобальних змінних:
увесь стан має жити в замиканнях — тести перевіряють, що екземпляри не заважають один одному.

```sh
# одноразова перевірка
npm run check -- exercises/01-javascript/11-scope-closures

# перевірка при кожному збереженні файлу
npm run check:watch -- exercises/01-javascript/11-scope-closures
```

Готово, коли всі тести зелені. Еталонне рішення лежить у `solution/`.
Відкривай його тільки після того, як розв'яжеш сам, щоб порівняти підходи.
