# Ката 01-13: модулі, import / export

Урок: «JavaScript: основи → Модулі: import / export».

Тут не один файл `exercise.js`, а маленький тестовий проєкт:

```
13-modules/
  legacy/summary.cjs   ← старий модуль у стилі CommonJS (не змінюй, лише читай)
  src/
    config.js          ← Завдання 1: налаштування
    data/users.js      ← Завдання 2: тестові користувачі
    checkout.js        ← Завдання 3: функція, що імпортує з двох інших файлів
    summary.js         ← Завдання 4: legacy/summary.cjs, переписаний на ESM
    index.js           ← Завдання 5: barrel-файл, що реекспортує все
```

Виконуй завдання по порядку: наступні файли імпортують попередні. У кожному файлі є коментар `TODO`.
Нові файли створювати не треба.

```sh
# одноразова перевірка
npm run check -- exercises/01-javascript/13-modules

# перевірка при кожному збереженні файлу
npm run check:watch -- exercises/01-javascript/13-modules
```

Останній тест запускає `src/index.js` у чистому Node.js — так само, як його запускав би справжній
тестовий фреймворк. Тож пропущене розширення `.js` в імпорті він помітить.

Готово, коли всі тести зелені. Еталонне рішення лежить у `solution/`.
Відкривай його тільки після того, як розв'яжеш сам, щоб порівняти підходи.
