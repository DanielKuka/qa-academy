Основний полігон курсу — власний навчальний застосунок у теці `apps/sandbox` (з'явиться перед
модулем 06). Він стабільний і вміє вмикати навмисні баги для перевірки твоїх тестів.

Публічні полігони нижче — для додаткової практики і різноманіття.

## Локальні інструменти

| Інструмент | Для чого |
|---|---|
| [Mailpit](https://mailpit.axllent.org/) | Локальний поштовий сервер у Docker — для тестування email-флоу |

<Aside type="caution" title="Правила поводження з чужими полігонами">
- Це чужі сервери, і вони безкоштовні. **Ніколи не запускай на них навантажувальні тести.**
- Не запускай сотні паралельних прогонів — отримаєш rate limit або бан.
- Публічні полігони падають і змінюються. Якщо тест раптом почав падати — спершу перевір сайт руками.
- Дані на них бачать інші люди: не вводь справжніх email, паролів чи персональних даних.
</Aside>
