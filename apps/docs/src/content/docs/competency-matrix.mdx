Назва посади нічого не означає без навичок за нею. Ця матриця — чесна відповідь на питання
«чи можу я вже називати себе Junior / Middle / SDET?». Кожен пункт — це те, що ти **робиш руками**,
а не те, про що «чув».

## Junior QA Automation

| Сфера | Вміння |
|---|---|
| Мова | Пише читабельний JS/TS: функції, масиви, об'єкти, async/await, базові типи |
| Playwright | Пише стабільні UI-тести з правильними локаторами і web-first assertions |
| Дебаг | Знаходить причину падіння через Trace Viewer і DevTools |
| Веб | Розуміє HTTP, статус-коди, DOM, cookies; читає вкладку Network |
| Git | Працює в гілках, робить merge request, розв'язує прості конфлікти |
| Мислення | Перетворює ручний тест-кейс на незалежний автотест |

## Middle QA Automation

| Сфера | Вміння |
|---|---|
| Архітектура | Будує фреймворк: Page Objects, фікстури, фабрики даних, конфіг оточень |
| API | Тестує API зі схемною валідацією, готує дані через API для UI-тестів |
| Стабільність | Тести незалежні, паралельні, без sleep; знаходить і усуває причини flaky |
| CI/CD | Налаштовує прогін у CI з шардингом, звітами, артефактами і секретами |
| Складні сценарії | Моки мережі, файли, листи, iframe, кілька вкладок, перевірки в БД |
| Рев'ю | Дає змістовний code review тестового коду колег |

## SDET

| Сфера | Вміння |
|---|---|
| Якість коду | Лінтер, форматер, unit-тести на утиліти фреймворку, патерни проєктування |
| Стратегія | Пише тест-стратегію продукту: рівні, ризики, що не автоматизуємо і чому |
| Широта | Базові навантажувальні тести, основи безпеки, доступність |
| Метрики | Вимірює стабільність і покриття, звітує про якість зрозуміло для бізнесу |
| Вплив | Впливає на testability продукту, працює з розробниками на ранніх етапах (shift-left) |
| Лідерство | Онбордить колег, задає стандарти команди, обґрунтовує технічні рішення |

## Як користуватися

Раз на місяць пройдись по таблиці і чесно відміть, що вже робиш без підказок. Слабкі місця —
це твій план на наступний місяць. На співбесіді будь-який рядок звідси може стати питанням
«розкажіть, як ви це робили».
