# Дорожня карта QA Академії

Стан на 2026-11-19.

## Бачення

Цілісна платформа, яка веде QA будь-якого рівня від нуля до SDET: мова (JS/TS) → веб і теорія →
Playwright → архітектура фреймворку → API → CI/CD → інженерія якості → портфоліо → співбесіда.
Спершу — для власного навчання автора; українською, з англійською версією.

## Принципи (узгоджено з власником)

- Курс будується **з нуля**, але кожен урок і модуль можна позначити «вже знаю».
  Пропуск модуля — лише після підтвердження всіх його контрольних навичок.
- Платформа — маршрут, а не копія документації: контекст «навіщо це QA» + посилання на офіційні джерела.
- Кожна тема має ката з автоматичною перевіркою; повідомлення тестів — підказки вчителя.
- У Playwright-модулях — мутаційна перевірка: тести учня запускаються проти версій sandbox-застосунку
  з навмисними багами (BUG=...) і мають їх ловити.
- Наскрізний фінальний проєкт (capstone) росте з першого модуля.
- Працюємо **по одному модулю**: узгодити → написати → перевірити → рев'ю власника → наступний.
- Хостинг: публічний GitHub + GitHub Pages + GitHub Actions. (GitLab відкинуто: на безкоштовному
  плані закінчувались CI-хвилини.) GitLab CI лишається уроком-порівнянням у модулі 11.

## Наступні кроки

1. Перший push на GitHub і ввімкнення Pages (Settings → Pages → Source: GitHub Actions).
2. Модуль 00 «Середовище розробника», 6 уроків: термінал, Node/npm, VS Code, Git, GitHub, читання
   документації. Узгодити обсяг з власником перед написанням.
3. Далі модуль 01 (уроки 02–14) з катами.
