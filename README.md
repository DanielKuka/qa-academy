# QA Академія

Цілісний шлях від ручного QA до SDET: JavaScript, TypeScript, Playwright, API-тестування, CI/CD
і підготовка до співбесіди. Українською, з англійською версією.

**Що відрізняє цей курс:**

- **Маршрут, а не довідник.** Кожна тема пояснює, навіщо вона тестувальнику, і веде в офіційну
  документацію в потрібний момент.
- **Практика з автоматичною перевіркою.** Ката з тестами, повідомлення яких — підказки вчителя.
- **Тести, які ловлять баги.** У Playwright-модулях твої тести запускаються проти версій застосунку
  з навмисними багами.
- **Пропуск відомого.** Будь-який урок або модуль (після самоперевірки) можна позначити як «вже знаю».
- **Один фреймворк на весь курс** — наприкінці це твоє портфоліо.

## Швидкий старт

Потрібен Node.js 22+.

```sh
npm install
npm run dev        # сайт курсу на http://localhost:4321
```

Розв'язуй ката та перевіряй себе:

```sh
npm run check -- exercises/01-javascript/01-variables-types
npm run check:watch -- exercises/01-javascript/01-variables-types   # перевірка при збереженні
```

Порада: працюй у власному fork або гілці, щоб твої рішення не змішувалися з оновленнями курсу.

## Структура

```
apps/docs/            сайт курсу (Astro Starlight, UA + EN)
  src/data/           curriculum.ts — модулі, уроки, контрольні навички
  src/content/docs/   уроки (MDX)
  tests/              Playwright-тести самої платформи
exercises/            ката з автоматичною перевіркою (Vitest)
.github/workflows/    CI і публікація на GitHub Pages
AGENTS.md             інструкції для AI-ментора (Claude Code та інші)
```

## Команди

| Команда | Що робить |
|---|---|
| `npm run dev` | Локальний сайт курсу |
| `npm run check -- <шлях>` | Перевірити свою кату |
| `npm run verify:solutions` | Перевірити еталонні рішення (для авторів курсу) |
| `npm run test:site` | Зібрати сайт і запустити Playwright-тести платформи |
| `npm run sync:modules` | Створити сторінки нових модулів з `curriculum.ts` |

## Статус

Курс у розробці. Готово: каркас платформи, карта всіх 15 модулів, прогрес і пропуск тем,
модулі 00 «Середовище» і 01 «JavaScript: основи» з катами. Уроки додаються по одному модулю.
